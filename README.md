# 📰 每日时事 · 新闻聚合工作区

一个**零依赖、无需注册、无需下载**的每日新闻工作区：每天自动更新科技热点、国际形势与地区热点，并按日期存档，可随时回看昨天及更早的内容。电脑和手机（同一 WiFi）直接用浏览器打开即可。

## 功能

- 🕐 **每天自动更新**：服务每 20 分钟检查一次，今天的快照超过 4 小时自动重新抓取，按天归档到 `data/YYYY-MM-DD.json`
- 📅 **时间选择**：顶栏日期条可切换「今天 / 昨天 / 更早」，也可用日期输入框选任意日期（存档从首次运行起积累）
- 🧭 **分类浏览**：左侧边栏切换 全部 / 科技 / 政治 / 国际 / **港澳台** / **国内热点** / **战争冲突** / **自然灾害** / 地区热点
- 🇭🇰 **港澳台**：香港、澳门、台湾最新新闻（中新网两岸频道、CGTN 台湾报道、滚动新闻自动分类）
- 🏙️ **国内热点**：国内城市热门新闻与民生动态（中新网社会/中国频道、CGTN 中国频道），自动标注城市标签（如 广州/佛山/兰州）
- ⚔️ **战争冲突**：集中展示全球战争与军事冲突（美以伊、叙利亚、俄乌战场等紧张局势）
- 🌪️ **自然灾害**：全球灾害速览，标注发生时间与地点（地震、台风、洪水、山火等），出行前可快速查看——来源 GDACS（联合国/欧盟联合监测）、USGS（美国官方地震台网）及各国官方媒体
- 🔍 **全库搜索**：顶栏搜索框输入关键词（如「霍尔木兹海峡」），自动搜索**全部历史存档**中的相关新闻；点开任意新闻卡片，会弹出详情并展示 **3-5 条相关引申新闻**（按内容相似度推荐），可直接跳转官方原文
- 🖥️ **桌面应用**：桌面上的「每日时事」应用，双击即可启动/打开/停止，无需终端
- 📱 **手机 App**：PWA 已配置，手机浏览器「添加到主屏幕」即可安装（见下文）
- 🔄 **双端同步更新**：电脑网页与手机 App 共用同一服务，功能更新后两边自动生效（网络优先缓存策略保证 App 不会停留在旧版本）

### 新闻更新时间说明

- **每条新闻的发布时间**：卡片右上角时间即官方发布的准确时间（今天的显示「时:分」，更早的显示「月日 时:分」）
- **快照自动更新**：服务每 20 分钟检查一次；今天的快照超过 4 小时自动重新抓取；抓取失败或内容过少会自动补抓
- **侧边栏底部**「更新于 时:分」为最近一次快照更新时间
- **各源更新频率**：中新网滚动/卫星社 约分钟级；中新网国际/中国/社会 约 10~30 分钟；CGTN 约 1 小时；GDACS/USGS 分钟~小时级

> 说明：俄罗斯卫星通讯社为俄官方媒体，俄乌/中东战况消息密集但立场偏俄，浏览时可自行判断；其余来源为中、联合国官方媒体。

## 使用方法

### 启动

```bash
./start.sh          # 或直接：node server.mjs
```

首次运行会自动回填最近 3 天的存档（约需 10~30 秒）。

### 打开

- 💻 电脑：<http://127.0.0.1:8787>
- 📱 手机：连**同一个 WiFi**，打开 <http://192.168.3.166:8787>（以 `start.sh` 输出的地址为准）

### 停止 / 重启

```bash
./stop.sh           # 停止
./start.sh          # 重新启动
```

### 手机「App 化」（PWA，免费）

网站已支持 PWA，手机打开后即可像 App 一样安装到主屏幕，**完全免费**：

- **iPhone**：用 Safari 打开 `https://uncaring-endurance-nimble.ngrok-free.dev` → 点「分享」按钮 → 「添加到主屏幕」→ 添加。桌面即出现「每日时事」图标，点开全屏运行。
- **Android**：用 Chrome 打开同一网址 → 菜单 → 「安装应用 / 添加到主屏幕」。

图标、全屏、离线壳缓存都已配置。建议用公网链接（HTTPS）安装以启用离线能力；上架苹果/谷歌应用商店的原生 App 才需要付费（Apple $99/年、Google Play $25 一次性），个人使用无必要。

### 桌面应用（推荐，无需终端）

桌面上的「📰 每日时事」应用，双击后弹出控制台，可一键：
- 🚀 启动并打开（自动启动新闻服务 + 公网隧道 + 打开浏览器）
- 🌐 打开页面　🔗 复制公网链接　🛑 停止服务

> 首次双击若系统提示安全警告，右键应用 →「打开」→ 再点「打开」即可。账号 Token、域名都保存在工作区内，换电脑/重装系统无需重新找 key。

## 常见问题

- **手机打不开？** 确认手机和电脑连的是同一个 WiFi；如 macOS 弹出防火墙提示，请允许 `node` 接受传入连接。
- **电脑休眠/关机后网站会停吗？** 会。本工作区运行在你的电脑上，**不修改任何系统休眠设置**：电脑睡眠/关机后服务和公网链接都会暂停；重新开机后双击桌面「每日时事」应用即可一键恢复。若需要 7×24 小时不间断运行，见下节。
- **运营网站会消耗 AI token / 需要付费吗？** 不会。新闻服务是纯程序抓取官方 RSS，不调用任何 AI；无论运行多久都不消耗 token、不产生费用。只有你与 AI 助手对话（当前这个工作台）才消耗额度。
- **想让朋友在外面也能打开？** 见下节「分享给朋友」。

## 分享给朋友（固定公网链接，免费）

本地地址只有同 WiFi 的设备能打开。用 ngrok 可以生成一个**永久固定**的公网链接，朋友在任何地方点开即可浏览，**无需注册、无需付费**。免费版每月 1GB 流量，个人分享绰绰有余。

### 当前已配置

- 固定链接：**https://uncaring-endurance-nimble.ngrok-free.dev**（已绑定本机账号 `ngrok.yml`）
- 启动：`./tunnel.sh`　停止：`./stop-tunnel.sh`
- 首次配置若换了账号：把新 Token 写入工作区 `ngrok.yml` 的 `authtoken:` 一行，域名写入 `tunnel-domain.txt` 即可

### 日常使用

- 分享前先确认新闻服务在运行：`./start.sh`，再 `./tunnel.sh`
- 需保持电脑开机；提示：ngrok 免费版首次访问可能显示「Visit Site」提示页，点一下即可进入

## 常见问题（续）

- **想在户外（外网）也能打开？** 见上节「分享给朋友」；或路由器端口转发 / Tailscale（免费组网）等方案。
- **某天内容偏少？** 网络波动可能导致个别源抓取失败，点「🔄 刷新今天」重试即可；服务也会自动重试。
- **换端口？** `PORT=9000 node server.mjs`，或修改 `start.sh`。
